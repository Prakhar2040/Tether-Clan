# Image credits

The photographs for Cubbon Park Run Club, Bengaluru Sketchbook Club and Sarjapur
Riders are placeholders, found through [Openverse](https://openverse.org) and used
here to make the demo look like a real product. The four Dice District images and the
two original covers are not in this list.

**These are other people's photographs.** The licences below are mostly CreativeCommons
non-commercial or no-derivatives, which this project does not comply with. That is a
deliberate, temporary choice for a demo behind a shared password — replace them before
the apps are public. Swapping one is a two-minute job: drop a new file into
`frontend/src/assets/` under the same name and reseed.
